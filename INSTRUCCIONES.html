⚠️ Acción Requerida

Para habilitar la sincronización automática bidireccional, necesitas configurar los permisos de la GitHub App de Abacus.AI.


🔐 Configurar Permisos Ahora

🔧 Paso 1: Configurar Permisos de GitHub App

1. Accede a la configuración de la GitHub App

Haz clic en el botón de arriba o visita:

https://github.com/apps/abacusai/installations/select_target

2. Selecciona tu cuenta

Selecciona la cuenta kensiahub

3. Configura el acceso al repositorio

En "Repository access", asegúrate de:

  • Seleccionar "All repositories" O
  • Seleccionar "Only select repositories" y agregar demo_github_sync

4. Verifica los permisos

En "Permissions", asegúrate de que tenga:

  • ✅ Contents: Read and write
  • ✅ Pull requests: Read and write
  • ✅ Webhooks: Read and write

5. Guarda los cambios

Haz clic en "Save" para aplicar la configuración.

🚀 Métodos de Sincronización

Método 1: Script de Ayuda Rápida (Recomendado)

Usa el script interactivo para sincronizar fácilmente:

cd /home/ubuntu/demo_github_sync
./sync.sh

Opciones disponibles:

  • 1) Push: Enviar cambios a GitHub
  • 2) Pull: Traer cambios de GitHub
  • 3) Status: Ver estado del repositorio
  • 4) Log: Ver historial de commits
  • 5) Diff: Ver diferencias con GitHub

Método 2: Comandos Git Manuales

Para enviar cambios a GitHub:

cd /home/ubuntu/demo_github_sync
git add .
git commit -m "Descripción de cambios"
git push origin main

Para traer cambios de GitHub:

cd /home/ubuntu/demo_github_sync
git pull origin main

Método 3: Sincronización Automática

Una vez configurados los permisos, consulta GUIA_SINCRONIZACION.md para instrucciones sobre:

  • Configuración de webhooks
  • Uso de APIs de Abacus.AI
  • Sincronización bidireccional automática

🧪 Prueba Rápida

Prueba 1: DeepAgent → GitHub

1. Edita el archivo index.html:

cd /home/ubuntu/demo_github_sync
nano index.html

2. Sincroniza con GitHub:

./sync.sh
# Selecciona opción 1 (Push)

3. Verifica en GitHub:

Ver en GitHub

Prueba 2: GitHub → DeepAgent

1. Edita el archivo en GitHub (usando el editor web)

2. Trae los cambios a DeepAgent:

cd /home/ubuntu/demo_github_sync
./sync.sh
# Selecciona opción 2 (Pull)

3. Verifica los cambios:

cat index.html
