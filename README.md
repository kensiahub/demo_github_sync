# Demo GitHub Sync

App de demostración para integración GitHub CI/CD con DeepAgent.

## Sincronización

**DeepAgent → GitHub:**
```bash
git add . && git commit -m "mensaje" && git push
```

**GitHub → DeepAgent:**
```bash
git pull origin main
```
